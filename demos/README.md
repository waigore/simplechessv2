# `demos/`

Gameplay demos: one folder per demo, each a reference artifact kept apart from the main code. Main code never imports from here.

Style and cataloged assets are required only when the demo must show or play them.

Contract: [`docs/demos.md`](../docs/demos.md) and [`docs/demo-style-assets.md`](../docs/demo-style-assets.md). Scope with `scope-gameplay-demo`; build with `create-gameplay-demo`.
