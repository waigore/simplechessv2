# Design requirement notes

- there is an untimed mode where players can take as much time to plan out their moves. alternatively, there is also a timed mode, with blitz/rapid as default settings (even time added for moves made to keep things interesting) — target: `specs/design/`
- for puzzle mode, it should be a continuous stream of puzzles fed to the player, similar to how it is for lichess or chess.com — target: `specs/design/`
- the player should have the option to begin a new session — target: `specs/ux/`
- if the player wants it, provide suggestions on the best move — target: `specs/design/features/`
