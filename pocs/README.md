# `pocs/`

Proofs of concept: one folder per PoC, kept apart from the main code. Main code never imports from here.

Product demo mode (limited full game) is not here—see [`docs/demo.md`](../docs/demo.md) and [`specs/design/demo.md`](../specs/design/demo.md).

Contract: [`docs/pocs.md`](../docs/pocs.md) and [`docs/poc-style-assets.md`](../docs/poc-style-assets.md). Log requests in [`docs/requirements/poc-requests.md`](../docs/requirements/poc-requests.md). Scope with `scope-poc`; build with `create-poc`.
