# Aesthetics Glossary

Authoring rules: [`.agents/specs/rules/aesthetics/glossary.md`](../../.agents/specs/rules/aesthetics/glossary.md).

## Terms

| Term | Definition | Detailed in |
|------|------------|-------------|
| Art pixel | The smallest drawn unit of pixel art, before scaling to the display. | [`aesthetics.md`](aesthetics.md) |
| Medium | The visual technique the whole game is drawn in, such as pixel art or low-poly 3D. | [`aesthetics.md`](aesthetics.md) |
| Palette set | The swatches one context, such as a stage or the interface, may use. | [`palette.md`](palette.md) |
| Reference image | An approved image that shows style elements the specs state. | [`references.md`](references.md) |
| Reference sheet | A to-scale HTML drawing of the palette or of the cast lineup. | [`sheets/`](sheets/) |
| Silhouette | The outline of a subject filled with one color, used to judge recognition. | [`form.md`](form.md) |
| Style pillar | A ranked style principle with a test a reviewer can apply to one asset. | [`aesthetics.md`](aesthetics.md) |
| Swatch | One named color with a fixed value and role. | [`palette.md`](palette.md) |
